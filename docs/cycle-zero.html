Cycle Zero — The First Cycle

Cycle Zero is the first full execution of the Tuneverse Cycle. It fails before naming, authority, memory, and its emerging systems can stabilize.

The Founder's Flame records the internal failure of the first cycle. The Anomaly records the external residue left after that collapse.

The later cycle documented in The Founder's Protocol is not the first cycle; it is the first stabilized one. Division 3825 coheres there as structure, authority, and memory finally hold.
